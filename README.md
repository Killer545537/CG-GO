# CG: GO

> Track performance and plan your academic targets in seconds.

**CG: GO** is a fast, distraction-free CGPA calculator built for students who want clarity and speed. It features both forward and reverse planning capabilities—calculate your current standing or determine exactly what grades you need to hit your future targets.

## Vibe Check

This project was **vibe-coded**. 
Built for speed, aesthetics, and pure utility. No bloat, just the good stuff.

## Tech Stack

- **Framework**: [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **UI Components**: [shadcn/ui](https://ui.shadcn.com/) + [Radix UI](https://www.radix-ui.com/)
- **Routing**: [TanStack Router](https://tanstack.com/router)
- **Forms**: [TanStack Form](https://tanstack.com/form)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Runtime**: [Bun](https://bun.sh/)

## Features

- **Instant Calculation**: Real-time updates as you type.
- **Reverse Planning**: Set a target CGPA and find out the required SGPA for future semesters.
- **Smart Formatting**: Clean, minimal UI with dark mode by default.
- **Smooth Transitions**: Polished interactions using Framer Motion.
